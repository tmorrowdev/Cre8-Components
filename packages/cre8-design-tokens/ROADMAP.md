## High-level WIPs
### Global file vs brand file

The pattern for this project is to start broad and work toward brand specifics. By naming brand tokens with the same structure, it simplifies maintenance for design styles shared between brands.

Example:
- All brands currently have a `Large Primary Button` and its various states.

If some tokens/styles only exist in certain brands, other brands that don't have that style would still need that token declared in order to not break an application if its theming switched between brands.

Example:
- Only `pharmacy` and `cre8` use the Emphasized button styling.

Currently, we need to **define the one-offs and define the boundaries** as it relates to certain styles that would be brand or application specific.
