# Choosing the Right Token

> Please note that this library is under active development and is meant to serve multiple brands and platforms. We appreciate you being patient with us as we create an architecture that serves our entire company. To stay up-to-date, be sure to check our change-log.

Design Tokens use our new color system. Color values won't always match those imported from the older brand/legacy themes colors.

For early access and release updates, <a href="https://git.express-scripts.com/ExpressScripts/cre8-design-tokens" target="_blank">see our cre8 design token repository on Github</a>

**How do I know which token to use for each instance and how do I read these tokens?**

Tokens are built using semantic names that help provide an understanding on how or when the tokens should be used.

**NOTE:** The Design Token's value will vary from brand to brand. The way one brand assigns a value to "**cre8.example.token.name**" may not be the same value as another brand. It's up to each individual brand and their application of the token to determine what works best for them when assigning values to tokens.

## Semantic Tokens

These are the semantic styles that should be used directly by the majority of components and by consuming designers on page related applications, with the exception of component-specific colors listed in the “component category tokens” section.
