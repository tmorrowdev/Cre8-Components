# Border Tokens
The border palette covers frame borders, outlines, page and content dividers, and component borders (input controls, form fields, etc)

>   **NOTE:** The Design Token's value will vary from brand to brand. The way one brand assigns a value to "**cre8-example-token-name**" may not be the same value as another brand. It's up to each individual brand and their application of the token to determine what works best for them when assigning values to tokens.

**A few examples** for choosing border tokens based on their color role: **default | error | success | info**

## Border Radius

Semantic tokens follow a framework that govern attributes of multiple components that share a similar usage context. For example, a switch and progress meter both use "cre8-border-radius-round".

<table>
<thead><tr><th>Token</th><th>Description</th><th>Shows as</th></tr></thead>
<tbody>
<tr><td>**cre8-border-radius-small**</td><td>Used to apply a smaller border radius for an object</td><td><div className="borderDiv" style={{ borderRadius: `4px`}}>Radius Small</div></td></tr>
<tr><td>**cre8-border-radius-default**</td><td>Used to apply the common or default size border radius of an object</td><td><div className="borderDiv" style={{ borderRadius: `8px`}}>Radius Default</div></td></tr>
<tr><td>**cre8-border-radius-large**</td><td>Used to apply the large border radius of an object</td><td><div className="borderDiv" style={{ borderRadius: `16px`}}>Radius Large</div></td></tr>
<tr><td>**cre8-border-radius-round**</td><td>Used to apply a round or almost fully rounded radius to objects</td><td><div className="borderDiv" style={{ borderRadius: `900px`}}>Radius Round</div></td></tr>
</tbody>
</table>


## Border Style

This token's value can vary depending on the brand use. It can be used as a default border style for objects depending on the value a brand has assigned it. Example: solid, dashed lines, bold, double line, etc.

## Border Width
The border width sets the width of an object's four borders.
