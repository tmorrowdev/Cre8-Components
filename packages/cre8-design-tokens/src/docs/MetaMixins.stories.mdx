# Meta Mixins

Eyebrow type styles reserved for pre-headers and meta text.

<img src={MetaHealine} width="904" />

**Example:**
```css
@import '~@tmorrow/cre8-design-tokens/lib/web/mixins/typography-usage';

.meta {
  @include cre8-typography-meta-default;
}
```
**Desktop**

* cre8-typography-meta-small
* cre8-typography-meta-default
* cre8-typography-meta-large
* cre8-typography-meta-default-sentence-case
