# Headline Mixins

Large type reserved for short, important text or numerals, usually as a heading to the smaller text below. Use headlines to title pages or sections.

**Example:**
```css
@import '~@esi/cre8-design-tokens/lib/web/mixins/typography-usage';

.headline {
  @include cre8-typography-headline-default;
}
```
**Desktop**
* cre8-typography-headline-xsmall
* cre8-typography-headline-small
* cre8-typography-headline-default
* cre8-typography-headline-large

**Mobile**
* cre8-typography-headline-xsmall-mobile
* cre8-typography-headline-small-mobile
* cre8-typography-headline-default-mobile
* cre8-typography-headline-large-mobile
