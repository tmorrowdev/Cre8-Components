# React Native Mixins

Using mixins simplifies the styling process and ensures the consistency in an app's design. Developers can use these react native specific typography mixins from <a href="https://git.express-scripts.com/ExpressScripts/cre8-design-tokens/" target='_blank'>cre8 Design Token</a> library to quickly style text elements throughout the mobile app development.

* cre8-body-small
* cre8-body-default
* cre8-body-large
* cre8-body-xlarge
* cre8-body-small-strong
* cre8-body-default-strong
* cre8-body-large-strong
* cre8-body-xlarge-strong

**Link**

* cre8-body-small-link
* cre8-body-default-link
* cre8-body-large-link

**Display**

## cre8 React Native Component
Using cre8 React Native Text component is an another alternative approach for getting above typography mixins. Based on your specific use case and preference you can choose the right suitable component variation. Use this <a href="https://d-cigna-nx-static.dev.digitaledge.cigna.com/storybook-rn/?path=/docs/cre8-ui-text--documentation">cre8Text</a> component throughout your app to maintain consistent typography styles.
```js
import { cre8Text } from '@cigna/react-native/cre8/ui/text';
```
