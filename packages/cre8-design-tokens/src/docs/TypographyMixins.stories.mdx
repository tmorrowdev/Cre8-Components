# How to use Mixins
> **Note:** Mixins can only be used within Sass files. We are working toward CSS only solutions for Typography in future versions of the cre8-design-tokens package.

Typography mixins are a set of reusable code snippets or functions in Sass that help manage typographic styles consistently across applications. These mixins streamline the process of defining typography-related properties such as `font-family`, `font-size`, `font-weight`, `line-height`, `text-decoration` and `text-transform`.  Define these mixins once and reuse them wherever necessary, this reduces redundancy in codebases and make it easy  to update styles globally. Design tokens and mixins provide a scalable way to manage and maintain typography styles in our cre8 Design System.

**Importing Mixins**: To integrate mixins into your project, use following import statement.

```js
    @import '~@esi/cre8-design-tokens/lib/web/mixins/typography-usage';
```
## Typography Mixins
>   **NOTE:** The Design Token's value will vary from brand to brand. The way one brand assigns a value to "**cre8.example.token.name**" may not be the same value as another brand. It's up to each individual brand and their application of the token to determine what works best for them when assigning values to tokens.

**Following mixins are tailored specifically for web applications and all the examples we are showing here are based on TCG theme.**

## Usage
### Using TCG Brand as example
Mixins are defined using the `@mixin` directive. To use the mixin, include it within a CSS rule using the `@include` directive. 

Here we are using TCG brand theme and this example is including `cre8-typography-headline-default` mixin. Note that this example mixin include provides TCG specific token related styles.   

```css
.headline {
  @include cre8-typography-headline-default; /* Using the original mixin */
  color: var(--cre8-content-default); /* Adding color definition */
}

/*`cre8-typography-headline-default` mixin provides following styles.*/

color: #333333;
font-family: 'Montserrat', sans-serif;
font-size: 2.5rem; // equivalent to 40px.
font-weight: 700;
line-height: 1.2; // equivalent to 48px.
text-decoration: none;
text-transform: none;
```

## Customize
> **NOTE:** These mixins provides brand specific styles, altering predefined mixins may affect app’s appearance and user experience . Please procced with caution when you customize and ensure thorough testing across different devices and platforms.

To overwrite mixins, simply redefine the properties within the mixin after including it in your project stylesheet. This will override the properties defined in the original mixin.

```css
@include cre8-typography-headline-default; /* Using the original mixin */
background-color: var(--cre8-color-bg-brand-strong); 
color: var(--cre8-color-content-knockout); /* updating color definition */
```

## Responsive Mixins
cre8 Design System has baked responsive nature into these typography mixins via tokens.  `Display`, `Headline` and `Title` mixins adjust appropriately based on the breakpoints, these mixins are iterated over the mobile breakpoint($cre8-breakpoint-md) and applied mobile styles accordingly. This ensures that these typography mixins adjust dynamically for mobile devices, you don’t have to write extra code for responsive nature.

> **NOTE:** Do not directly use mobile specific mixins in web applications, design tokens are seperate and specific to each platform. 

Responsive Mixins:
```css
@mixin cre8-typography-title-xlarge();
@mixin cre8-typography-title-large();
@mixin cre8-typography-title-default();
@mixin cre8-typography-title-small();
@mixin cre8-typography-headline-large();
@mixin cre8-typography-headline-default();
@mixin cre8-typography-headline-small();
@mixin cre8-typography-headline-xsmall();
@mixin cre8-typography-display-large();
@mixin cre8-typography-display-default();
@mixin cre8-typography-display-small();
```
Example: Full details of `display-default` mixin
```css
@mixin cre8-typography-display-default() {
    font-family: var(--cre8-typography-display-default-mobile-font-family);
    font-size: var(--cre8-typography-display-default-mobile-font-size);
    font-weight: var(--cre8-typography-display-default-mobile-font-weight);
    line-height: var(--cre8-typography-display-default-mobile-line-height);
    text-decoration: var(--cre8-typography-display-default-mobile-text-decoration);
    text-transform: var(--cre8-typography-display-default-mobile-text-transform);
    @media all and (min-width: $cre8-breakpoint-md) {
        font-family: var(--cre8-typography-display-default-font-family);
        font-size: var(--cre8-typography-display-default-font-size);
        font-weight: var(--cre8-typography-display-default-font-weight);
        line-height: var(--cre8-typography-display-default-line-height);
        text-decoration: var(--cre8-typography-display-default-text-decoration);
        text-transform: var(--cre8-typography-display-default-text-transform);
    }
}
```
