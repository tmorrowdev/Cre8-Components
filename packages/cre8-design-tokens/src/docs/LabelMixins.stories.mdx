# Label Mixins

Small-sized type used for medium-emphasis text that is shorter in length.

**Example:**
```css
@import '~@esi/cre8-design-tokens/lib/web/mixins/typography-usage';

.label {
  @include cre8-typography-label-default;
}
```
**Desktop**
* cre8-typography-label-small
* cre8-typography-label-default
* cre8-typography-label-large
