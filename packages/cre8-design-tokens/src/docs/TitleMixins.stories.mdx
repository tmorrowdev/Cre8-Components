# Title Mixins

Medium-sized type used for medium-emphasis text that is shorter in length. Use titles for card headings, headings for visualizations or tables, and body-text subheadings.

**Example:**
```css
@import '~@esi/cre8-design-tokens/lib/web/mixins/typography-usage';

.title {
  @include cre8-typography-title-default;
}
```
**Desktop**

* cre8-typography-title-small
* cre8-typography-title-default
* cre8-typography-title-large
* cre8-typography-title-xlarge

**Mobile**

* cre8-typography-title-small-mobile
* cre8-typography-title-default-mobile
* cre8-typography-title-large-mobile
* cre8-typography-title-xlarge-mobile
