# Body Mixins

Small-sized type used for the primary content on the page (longform text, body copy, etc).

**Example:**
```css
@import '~@tmorrow/cre8-design-tokens/lib/web/mixins/typography-usage';

.body {
  @include cre8-typography-body-default;
}
```
* cre8-typography-body-small
* cre8-typography-body-small-strong
* cre8-typography-body-default
* cre8-typography-body-default-strong
* cre8-typography-body-large
* cre8-typography-body-large-strong
* cre8-typography-body-xlarge
* cre8-typography-body-xlarge-strong
