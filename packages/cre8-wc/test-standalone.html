Usage Instructions

Individual Component Usage:

  1. ES Module Import: Use <script type="module" src="./lib-components/{component-name}/components/{component-name}/{component-name}.js"></script>
  2. Dependencies: All Lit and other dependencies are bundled, no additional imports needed
  3. Web Components: Once imported, use components as regular HTML elements

Available Individual Components:

  • cre8-element (base component)
  • cre8-form-element (base form component)
  • cre8-field (base field component)
  • card
  • layout, layout-container
  • And many more... (check lib-components directory)
