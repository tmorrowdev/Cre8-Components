
### Option 2: Start Web Interface (1 minute)  
```bash
cd src/
python3 web_interface.py
```
**Result**: Opens http://localhost:5000 for drag-and-drop CSV uploads

### Option 3: Export Your Data (Any CSV file)
```bash
cd src/
python3 -c "
from dashboard_export import export_dashboard_charts
files = export_dashboard_charts('path/to/your/data.csv')
print(f'✅ Created {len(files)} visualizations!')
"
```
